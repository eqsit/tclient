tclient+ avoid preset

This release starts with the author's avoid and rocket settings.
Avoid and rocket debug logging are disabled.

Rocket mode starts in Normal with the speed-boost option enabled. Aggressive
mode remains available in the Rocket settings or with:

tc_anti_void_rocket 2

The optional "Smart priority: rocket-first only below" mode is included but
disabled by default. It can be enabled in the Rocket settings or with:

tc_anti_void_rocket_smart_priority 1
