# Локальный boost для rocket save

F12 → **Boost: faster rocket saves**, либо `tc_rocket_boost 1`.
Выключение: `tc_rocket_boost 0`.

Boost работает только при обычном ракетном спасении от прогнозируемой
опасности. На безопасном граунде и без угрозы дополнительных выстрелов нет.

Поиск спасения, движение, хук, ожидание, перезарядка и возврат оружия взяты
из сохранённой версии kog-kinetix-8. Сначала находится обычный проверенный
rocket save. После этого boost сравнивает варианты ракетного прицела,
сохраняя его движение и последовательность хуков. Смена оружия идёт по
исходной логике; угол оптимизируется только когда граната готова к выстрелу.
Если более быстрый
безопасный вариант не подтверждён или закончился бюджет, остаётся исходный
спасательный выстрел.

Клавиши влево/вправо задают желаемое направление даже против инерции.
Вертикальное направление учитывает новый прыжок и движение вверх/вниз.
Для явного вертикального предпочтения доступны команды удержания
`+tc_boost_up` и `+tc_boost_down`; их можно назначить на свободные клавиши.
Они сочетаются с влево/вправо для диагональных направлений.

Оценка учитывает продвижение и скорость после взрыва. Новый вариант
проходит настоящую симуляцию снаряда, взрыва, движения и смены направления.
Он должен оставаться безопасным на всём ракетном горизонте, в том числе
при смене горизонтального направления, и взрываться не позже исходного сейва.
Оптимизация ограничена временем и выбирает лучший проверенный вариант.

В режиме boost угол спасательного выстрела сохраняется на отпускании
кнопки до серверного подтверждения. Это защищает от позднего ввода, когда
сервер получает счётчик отпускания с пропущенным нажатием. Дополнительного
нажатия нет; хук и следующие ручные выстрелы сохраняют свой прицел.
При открытом F12 режим boost передаёт вычисленный ввод вместе с отпусканием
автоматического выстрела, чтобы меню не удерживало нажатие ракеты.

Локальные изменения не публикуются без отдельной просьбы. Сохранённая
версия до boost: https://github.com/eqsit/tclient/releases/tag/v-tclient-plus-kog-8-20261004
