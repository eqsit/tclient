# Boost для rocket save

F12 → **Boost: faster rocket saves**, либо `tc_rocket_boost 1`.
Выключение: `tc_rocket_boost 0`.

Boost работает только при обычном ракетном спасении от прогнозируемой
опасности. На безопасном граунде и без угрозы дополнительных выстрелов нет.

Поиск спасения, ожидание, перезарядка и возврат оружия взяты
из сохранённой версии kog-kinetix-8. Сначала находится обычный проверенный
rocket save. После этого boost сравнивает варианты ракетного прицела,
сохраняя его движение и последовательность хуков. Смена оружия идёт по
исходной логике; угол оптимизируется только когда граната готова к выстрелу.
Если более быстрый
безопасный вариант не подтверждён или закончился бюджет, остаётся исходный
спасательный выстрел.

Клавиши влево/вправо задают желаемое направление даже против инерции.
Вертикальное направление учитывает новый прыжок и движение вверх/вниз.
Для явного вертикального предпочтения доступны команды удержания
`+tc_boost_up` и `+tc_boost_down`; их можно назначить на свободные клавиши.
Они сочетаются с влево/вправо для диагональных направлений.

Нажатое влево/вправо задаёт горизонтальный буст; случайная скорость падения
не наклоняет это предпочтение вниз. Прыжок и явное вертикальное направление
задают вертикальный или диагональный буст.

Оценка сравнивает скорость сразу после взрыва и немного учитывает продвижение.
После обзора углов поиск уточняет направление вокруг лучшего результата.
Каждый вариант проходит настоящую симуляцию снаряда, взрыва и движения.
Он должен спасти от текущей угрозы, выдержать задержку ввода на один тик
и не приблизить следующую опасность по сравнению с обычным сейвом, в том
числе при смене горизонтального направления. Если обычный сейв безопасен
на всём ракетном горизонте, усиленный должен быть безопасен на всём горизонте.
Взрыв допускается чуть позже исходного, только в пределах заданного времени
полёта и после этих проверок. Поиск ограничен временем и числом симуляций;
при нехватке бюджета остаётся проверенный вариант.

При экстренном хуке boost также сравнивает другие точки зацепа и длительности
импульса. Приоритет получают безопасные зацепы по направлению игрока и
с сохранением скорости. Тяга назад остаётся запасным сейвом, когда более
быстрый вариант не подтверждён. Для уже зацепленного хука учитывается
положение якоря относительно текущей позиции, включая пролёт мимо него.
Замена должна подтвердить текущий сейв и не приблизить следующую опасность
или сделать задержку ввода опаснее исходного варианта. Поиск ограничен
бюджетом; проверенный исходный хук сохраняется при его исчерпании.
При выключенном boost действует прежняя логика движения и выбора хуков.

F12 → **Auto rehook after interruption** — возобновление ручного хука после
прерывания авойдом. По умолчанию включено. Выключение через консоль:
`tc_avoid_auto_rehook 0`; включение: `tc_avoid_auto_rehook 1`.
При выключении после прерывания нужно отпустить кнопку хука и нажать снова.
Экстренные хуки авойда продолжают работать. Настройка сохраняется в профиле;
ожидание нового нажатия хранится отдельно для каждого ти.

В режиме boost угол спасательного выстрела сохраняется на отпускании
кнопки до серверного подтверждения. Это защищает от позднего ввода, когда
сервер получает счётчик отпускания с пропущенным нажатием. Дополнительного
нажатия нет; хук и следующие ручные выстрелы сохраняют свой прицел.
При открытом F12 режим boost передаёт вычисленный ввод вместе с отпусканием
автоматического выстрела, чтобы меню не удерживало нажатие ракеты.
